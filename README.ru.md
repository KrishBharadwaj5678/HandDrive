# ✋ Hand привод

**Hand привод** это проект компьютерного зрения на Python, который позволяет управлять машиной в игре **Hill Climb Racing** с помощью жестов рук.

![HandDriveDemo](https://github.com/KrishBharadwaj5678/HandDrive/raw/main/HandDriveDemo.gif)

## 🧠 Возможности

| Функция                                             | Описание                                                                  |
| --------------------------------------------------- | ------------------------------------------------------------------------- |
| 🖐️ **Распознавание жестов рук в реальном времени** | Использует **MediaPipe** для быстрого и эффективного отслеживания рук     |
| 🚗 **Интуитивное управление жестами**               | 🖐️ **Открытая ладонь** — ускорение <br/> ✊ **Сжатый кулак** — торможение |
| 🕹️ **Автоматизация игры**                          | Разработано для **Hill Climb Racing**                                     |
| 🖥️ **Управление через веб-камеру**                 | Не требуется дополнительное оборудование — только камера                  |
| 🎯 **Точное распознавание пальцев**                 | Хорошо работает при разном освещении                                      |
| 🔄 **Опыт без рук (hands-free)**                    | Игра без клавиатуры и мыши                                                |
| 📊 **Визуальная обратная связь в реальном времени** | Отображает ключевые точки руки и распознавание жестов                     |

---

## 🛠️ Технологии

| Технология       | Описание                                      |
| ---------------- | --------------------------------------------- |
| 🐍 **Питон 3**  | Основной язык разработки                      |
| 🤖 **медиапайп** | Отслеживание рук и пальцев в реальном времени |
| 🖥️ **OpenCV**   | Работа с веб-камерой и обработка изображений  |
| 🧰 **CVZone**    | Упрощает работу с OpenCV и MediaPipe          |
| 🎮 **pyautogui** | Эмуляция нажатий клавиш для управления игрой  |

---

## 🚀 Как это работает

1. 🖐️ **Открытая ладонь (все пальцы выпрямлены)**
   → Имитирует нажатие клавиши **ускорения**, чтобы машина ехала **вперёд**

2. ✊ **Сжатый кулак (пальцы согнуты)**
   → Имитирует нажатие клавиши **тормоза**, чтобы машина **остановилась** и ехала **назад**

## 📦 Установка

### 1️⃣ Клонировать репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/HandDrive.git
```

### 2️⃣ Перейти в папку

```bash
cd HandDrive
```

### 3️⃣ Установить зависимости

```bash
pip install -r requirements.txt
```

### 4️⃣ Запустить проект

```bash
python main.py
```
