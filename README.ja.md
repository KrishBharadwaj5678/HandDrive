# ✋ ハンドドライブ

**ハンドドライブ** は、Python ベースのコンピュータビジョンプロジェクトで、**ジェスチャー操作によって「Hill Climb Racing」** の車をコントロールできるシステムです。

![ハンドドライブ](https://github.com/KrishBharadwaj5678/HandDrive/raw/main/HandDriveDemo.gif)

## 🧠 機能

| 機能                       | 説明                                          |
| ------------------------ | ------------------------------------------- |
| 🖐️ **リアルタイム手のジェスチャー認識** | **MediaPipe** を使用して高速かつ効率的に手をトラッキング         |
| 🚗 **直感的なジェスチャー操作**      | 🖐️ **開いた手** → アクセル <br/> ✊ **握った手** → ブレーキ |
| 🕹️ **ゲーム自動操作**          | **Hill Climb Racing** 向けに設計                 |
| 🖥️ **ウェブカメラ操作**         | 追加のハードウェア不要（Webカメラのみ）                       |
| 🎯 **高精度な指認識**           | さまざまな照明条件でも安定して動作                           |
| 🔄 **ハンズフリー体験**          | キーボードやマウスなしでプレイ可能                           |
| 📊 **リアルタイム可視化**         | 手のランドマークとジェスチャーを表示                          |

---

## 🛠️ 使用技術

| 技術               | 説明                           |
| ---------------- | ---------------------------- |
| 🐍 **パイソン3**  | メイン開発言語                      |
| 🤖 **メディアパイプ** | 手と指のリアルタイムトラッキング             |
| 🖥️ **OpenCV**   | ウェブカメラ処理・画像処理                |
| 🧰 **CVゾーン**    | OpenCV と MediaPipe の簡略化ライブラリ |
| 🎮 **pyautogui** | キーボード入力をシミュレーション             |

---

## 🚀 動作の仕組み

1. 🖐️ **開いた手（すべての指を伸ばす）**
   → アクセルキーを押した状態になり、車が**前進**

2. ✊ **握った手（すべての指を曲げる）**
   → ブレーキーキーを押した状態になり、車が**停止または後退**
